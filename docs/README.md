# Documentation

Project documentation.

## Structure

```
docs/
├── architecture/    # System design, diagrams, decisions
├── api/             # API documentation
├── deployment/      # Deploy guides, infra setup
└── decisions/       # Architecture Decision Records (ADRs)
```

## Conventions

- Architecture docs: Markdown with diagrams (Mermaid.js)
- API docs: OpenAPI/Swagger spec + markdown guides
- Deployment: Step-by-step runbooks
- ADRs: Numbered, dated, with context and consequences
