# Utility Classes

Shared utility functions.

## Expected Utils

- `FileUtils.java` - File type detection, size formatting
- `TextSanitizer.java` - Text cleaning for embedding input
- `DateUtils.java` - Date parsing, formatting
- `VectorUtils.java` - Embedding vector operations
- `ValidationUtils.java` - Input validation helpers

## Conventions

- Static utility methods only
- No Spring dependencies
- Fully testable
