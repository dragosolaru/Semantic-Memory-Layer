# Assets

Static resources: images, fonts, icons.

## Structure

```
assets/
├── images/       # PNG, SVG, JPG resources
├── fonts/        # Custom font files
└── icons/        # App icons, tab icons
```

## Conventions

- Use SVG where possible (react-native-svg)
- Name files descriptively: `icon-search.svg`, `logo-primary.svg`
- Keep original high-res versions, let build process optimize
