# Navigation

React Navigation configuration and route definitions.

## Structure

- `RootNavigator.tsx` - Main navigator (stack/tabs)
- `types.ts` - Route param list definitions
- `linking.ts` - Deep linking configuration
- `useNavigation.ts` - Typed navigation hook

## Conventions

- All route types defined in `types.ts`
- Use typed navigation hook everywhere
- Deep linking for asset sharing (V2)
