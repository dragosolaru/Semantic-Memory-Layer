# Utility Functions

Pure helper functions, not React-specific.

## Expected Utils

- `date.ts` - Date formatting, relative time
- `file.ts` - File type detection, size formatting
- `text.ts` - Text truncation, sanitization
- `validation.ts` - Input validation helpers
- `navigation.ts` - Navigation helpers

## Conventions

- Pure functions only
- No side effects
- Fully testable
